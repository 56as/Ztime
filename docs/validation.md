## 静态检查提示的处理

WebView 的 JavaScript 提示：这是共享本地界面所必需；只加载包内资产，禁用普通文件 / 内容访问、混合内容与外部资源请求，动态应用名和设备名经过转义，不加载远程页面。

自定义 X509TrustManager 提示：局域网使用自签名设备证书，因此不依赖公共 CA；实现要求叶证书 SHA-256 与首次配对绑定值完全一致，并检查有效期，不采用信任任意证书的实现。仍需真机验证配对及证书不匹配时的用户体验。

依赖版本提示：固定 WorkManager 2.10.1 以匹配当前 SDK 35 构建组合；没有仅为消除“有新版本”提示而升级平台依赖。

另已补充 Android 12+ 的云备份及设备迁移排除规则，扫码页不固定屏幕方向。

## 尚未验证

没有连接荣耀 WIN RT 真机，因此未实测：使用权限授予后的具体事件、分屏与锁屏行为、后台存活与省电设置、二维码相机、路由器广播与设备真实互传、长时间准确率和耗电。浏览器窄屏测试不能替代真机验收。

没有进行独立安全审计，也没有将源码发布到远程平台。调试签名 APK 用于本轮个人验收，正式对外发行应使用单独管理的发行签名。
