# Ztime UI 设计稿与 UX 交互原型

双击同目录的「打开Ztime设计稿.cmd」。默认地址为本机 41875 端口。评审服务使用 Python 3，仅在本机运行。

- **按钮样式第一版**　[桌面控件手册](http://127.0.0.1:41875/#desktop-home/controls)、[手机控件手册](http://127.0.0.1:41875/#mobile-home/controls)。按页面工具、范围选择、提交、文件导出和危险操作分组。可以点选设备、更改日期与统计日起点、演练删除确认。实际页面见[周报导出](http://127.0.0.1:41875/#desktop-week/report)和[手机设置](http://127.0.0.1:41875/#mobile-settings/data)。所有按钮在本机示例数据上演示。
- **直接打开功能画板**　[浏览器识别设置](http://127.0.0.1:41875/#desktop-settings/extension)、[网站明细](http://127.0.0.1:41875/#desktop-home-detail-browser)、[桌面周报预览](http://127.0.0.1:41875/#desktop-week/report)、[手机周报预览](http://127.0.0.1:41875/#mobile-week/report)。首页也有对应入口。
- **自己试改**　点「试改文字 / 字号」后选一个标题、按钮文字或说明，在右侧修改，画板会实时预览。保存后有固定编号，刷新后仍生效。点取消可放弃未保存的编辑，点「撤回试改」可撤销已保存的编辑。这些修改属于本机设计稿。布局和流程用「添加批注」选点描述。
- **看 UI**　选择桌面或手机，再选择今日、每周、设备、设置或布局编辑态。画板使用 0.2.3 的布局和固定示例数据，手机画板采用 Android 的界面分支。
- **试 UX**　从今日或每周点击排行中的应用，再关闭明细。点击「演练配对流程」可以切换手机与电脑视角，体验成功、拒绝、超时及重试。配对流程中的文字和过渡页是供评审的提案。
- **提意见**　点击「添加批注」，再点到具体位置，选择 UI 或 UX，写明预期并保存。每条意见有固定编号；标为已处理后仍可重新打开。关闭浏览器后，编号和意见仍然保留。
- **试日常同步**　选择设备页，从桌面或手机画板点击「立即同步」。首次演练会合并两端的示例记录，切换画板可核对结果；再点一次会显示「已是最新」。将演练条件切为「对端暂时不可达」可查看失败提示，恢复为可互访后按「重试」。可以在每个结果页上选点批注。
- **按编号改稿**　向协作者说「请看第 3 条，先改设计稿」。本地清单位于本目录的 `review-notes.json`，第一次保存时生成。它记录画板、控件、相对落点、视口尺寸、操作路径、类型和处理状态。点击「定位 / 编辑」可回到对应画板。改稿后由评审者复核。
- **维护设计稿**　`boards/` 下的 HTML 与样式可独立修改；文件名区分设备、页面和流程状态。修改后刷新页面检查。正式产品的代码和数据与这里分开保存。
