# Ztime · 时间账本

免费、MIT 开源、本地优先的个人应用时间统计工具。Windows 记录前台应用，Android 读取授权后的系统应用使用事件；通过局域网加密配对同步，不需要账号或云服务。

## 第一版功能

- 今日总览：手机 / 电脑分别计时、应用排行、时段图、本周与上周同期、应用变化榜。
- Windows 首页模块可拖拽、缩放、隐藏，手机独立单列布局，可上下移动和隐藏。
- 模块支持设备筛选，应用排行榜可切换列表与条形图，时段分布可切换柱状图与折线图。
- 统计日默认从凌晨 04:00 开始，可修改时区与起点。周从周一开始，比较相同进度。
- 两端保存 SQLite 原始时段；增量同步、重复记录校验、删除标记传播、统计设置冲突处理。
- 二维码配对、电脑明确确认、HTTPS 与证书指纹绑定；电脑地址变更时尝试局域网发现。
- JSON / CSV 导出，暂停 / 恢复记录，浅色 / 深色 / 跟随系统主题。无付费历史期限。
- Windows 关闭窗口后保留托盘，托盘退出停止计时。登录时启动需要本人在设置中开启。

## 计时定义

**Windows**：前台应用一直计时，直到切换、锁屏、休眠或停止程序。不因没有键鼠输入而停止。因此“前台应用时长”不等同于实际专注时长。采集以约 1.5 秒轮询，异常退出后的未知间隔不会补成长时间使用。

**Android**：只统计亮屏且已解锁时的前台应用，熄屏音频不计入。首次授权会尝试从最近两天的系统事件恢复记录，之后增量采集。系统可用事件历史有限，中断较久可能缺记录；不是永久可回溯的系统数据库。

同一时段同时使用两端时分别保留各自记录，第一版不计算个人跨设备净时长。更改日界线只重算展示，不删除原始记录。

## 使用

### Windows

解压完整的 `TimeLedger-windows-x64` 文件夹，双击 `Ztime.exe`。不需要安装 Node.js。数据保存在便携程序旁的 `data` 文件夹；请不要只移动 exe。

关闭窗口保留托盘计时。在托盘选择“退出并停止记录”才会完全退出。自动启动是可选项，默认不开启。

### Android

安装 `Ztime-android-debug.apk`，打开时间账本，按提示允许“应用使用情况访问”。需要后台保持时，可从设置进入手机的应用后台管理。没有要求无障碍权限、屏幕录制或通讯录权限。扫码配对仅使用相机权限，也可以粘贴配对信息。

打开电脑的“设备同步 → 生成配对二维码”，手机扫描并点击“确认连接”，再在电脑端允许配对。不要扫描不信任的配对信息。

两端应处于同一可互访的局域网。Windows 防火墙若询问网络访问，只在自己信任的专用网络允许。默认使用 TLS TCP 40327 和发现用 UDP 40328；界面的 HTTP 端口仅绑定本机回环地址，不向局域网提供统计页面。

Android 在前台约每 30 秒采集并尝试同步，后台通过 WorkManager 调度约每 15 分钟执行一次，实际可能被省电策略推迟。电脑端“立即同步”会说明需等待手机连接，手机端可主动触发同步。当前数据到何时，以最后成功同步时间为准。

### 验证边界

核心统计、同步协议、界面与 Windows 正常桌面会话由自动化检查覆盖。安卓 APK 能构建不等同于荣耀 WIN RT 实机验收；后台存活、锁屏 / 分屏事件、路由器广播发现、二维码相机和两端真实网络联通仍须实机验证。

## 隐私与数据

采集字段仅包括应用名称 / 标识、起止时间、设备来源和必要同步状态。不读取窗口标题、文档名称、网址、屏幕截图、消息或键盘内容。没有账号、广告 SDK、遥测或云端 AI。Android 系统云备份已关闭。

传输使用 HTTPS，手机按首次配对二维码中的 SHA-256 指纹校验电脑证书。已配对请求使用随机令牌，电脑只存令牌哈希。局域网发现只广播服务身份，不广播使用记录。原始 SQLite 文件、电脑证书私钥和手机配对凭据保存在本地，**当前不提供本地数据库加密**。

删除记录会生成删除标记，在下次同步时传播，避免旧副本重新导入。解除配对会停止后续同步，已经收到的记录仍保留，可在数据管理中删除。导出包含原始设备标识，请自行选择如何保存。

## 开发

需要 Node.js 24+。生产依赖只有 `qrcode` 和 `selfsigned`，SQLite 使用 Node 内建接口；桌面框架为 Electron。

```powershell
pnpm install
pnpm start                 # 桌面程序
node desktop/server.js     # 浏览器开发入口，仅用于调试
node --test tests/*.test.js
node scripts/package-windows.js
```

Windows 原生采集由 `desktop/collector.ps1` 调用系统 API，仅查询前台进程名和锁屏状态。受限沙箱可能无法读取前台窗口，需要从正常 Windows 桌面启动程序。

项目中 `scripts/verify-ui.mjs` 和 `scripts/verify-electron.mjs` 支持 Playwright 检查。将 `PLAYWRIGHT_PATH` 设置为自己的 `playwright` 模块路径；测试数据位于临时目录，截图文件名注明测试数据，不写入真实账本。

### Android 构建

需要 JDK 17、Android SDK 35、Build Tools 35.0.0、Gradle 8.13。Gradle 构建会自动把共享 UI 和日期统计代码复制到 APK 内部，不依赖远程网页。

```powershell
cd android
.\gradlew.bat assembleDebug
```

若使用已安装的 Gradle，也可以 `gradle -p android assembleDebug`。SDK 路径由 `ANDROID_HOME` 或 `android/local.properties` 指定。开发签名密钥自动生成到项目内被忽略的 `.tools/debug.keystore`；正式发布需要自己的发行签名。本项目不包含发行私钥。

`scripts/bootstrap-android.py`、`scripts/install-sdk.py` 和 `scripts/build-android.ps1` 是本次项目内工具链的辅助脚本，不修改系统 PATH；一般开发者直接用 Android Studio 或自己的 SDK 即可。

## 目录

```text
desktop/   Windows 主进程、本地 API、SQLite、TLS 同步、前台采集
android/   Android Activity、UsageStats 采集、WorkManager、原生安全桥
web/       两端共用的本地仪表盘
shared/    日界线、时区、周对比、时段汇总
tests/     核心与协议检查
scripts/   构建、打包和界面验证
```

Ztime 源码按 MIT 许可发布。框架与依赖保留各自的第三方许可。


## 0.2.0 仪表盘

今日与每周分别保存模块布局。点击右上角“编辑”，可修改标题、拖动、调整宽高和图表样式，或移除模块；在编辑区底部可以添加回来。顶部信息卡片同样可编辑，移除后仍保留页面编辑入口。手机继续使用单列布局，可排序和移除。

新增应用占比（饼图/环形图）、设备占比和统计摘要；每周包含应用排行、每日趋势与同期变化。设备累计时长保留多设备重叠时间。设置页同一行卡片等高。

0.2.1：放大时长卡片的中文单位；编辑时可分别调整并保存数字字号和单位字号。

0.2.2：设置 → 记录与外观新增八种主题色，支持浅色、深色和跟随系统；外观配置保存在本机，重新启动后保留。

0.2.3：采用选定的沙漏 Z 图标，Windows 程序、托盘、安卓启动器和侧栏品牌统一。
